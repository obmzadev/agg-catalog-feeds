# agg-catalog-feeds

Mirror of the AGG Pre-Owned vehicle catalogue feeds generated by the AutoTrader Feed Generator plugin on aggwestrand.co.za. The shared host blocks Meta's crawler, so Meta (and TikTok) fetch the files from here instead.

## How it works
- GitHub Actions workflow `Mirror catalogue feeds` runs daily at 11:00 UTC (13:00 SAST) and on manual dispatch.
- It downloads the plugin's CSVs, validates them (`scripts/validate.py`) and publishes them to `docs/`, served by GitHub Pages.
- If a file fails validation (wrong template, no rows, duplicate IDs, row count more than halved) the previously published copy is kept and the run fails, so GitHub emails the repo owner.
- The TikTok CSV is optional: a failure there is logged but does not fail the run.

## Feed URLs (once Pages is enabled: Settings > Pages > Deploy from branch > main > /docs)
- Facebook/Meta: https://obmzadev.github.io/agg-catalog-feeds/autotrader-facebook-catalog.csv
- TikTok: https://obmzadev.github.io/agg-catalog-feeds/autotrader-tiktok-catalog.csv

## Rules
- Public repository: only public vehicle-listing data belongs here. Never commit credentials or tokens.
- `docs/last-checked.txt` is updated every run, which also keeps scheduled workflows from being auto-disabled for inactivity.
- The plugin generation time must be earlier than 13:00 SAST; Meta's scheduled pull is 14:00 SAST.
